## 1. ガイダンスの位置づけ

- 名古屋文理大学 情報メディア学部 情報メディア学科の1年生向けコースガイダンス。
- 学科には4コースがある：情報システム／映像メディア／サウンド制作／メディアデザイン
  （2016年度当時はメディアデザインではなく「メディアプランニング」）。
- フレッシュマンゼミの時間に、コースごとのガイダンスが行われる。
- 2026年度の持ち時間は15分。スライドは使わず、mocopi で動くアバターによる VR プレゼンで行い、最後に学生用ゲームへ QR コードで誘導する。

## 2. 情報システムコースの概要（大学公式サイトの要約）

出典：https://www.nagoya-bunri.ac.jp/department/media/is/

- 情報システムの基礎知識を土台に、プログラミング言語、AIの仕組み、Webプログラミング、アプリ開発、データサイエンスなどを体系的に学び、理論と実践の両方を身につけるコース。
- 目指す人材：身近なアプリやゲーム、企業や社会インフラを支えるシステムの設計・開発者、AI技術者、データサイエンティストなど。
- キーワード：情報処理、プログラミング、ゲーム、アプリ、開発、AR、VR、データサイエンス、AI
- サイトで紹介されている例：
  - 長谷川研究室：VR、AR、AI、プログラミング、システム開発、情報教育、情報科学実験など幅広い研究。イベントへの作品出品。
  - ゲームプログラミング（小橋先生）：ゲームのアルゴリズム、C# の基本文法、3DCG ツールに共通する操作を学び、ゲーム制作の全工程を体験する。
  - 情報処理演習（松原先生）：表計算ソフトの応用と、マクロ言語（VBA）による業務手順の自動化。

過去のガイダンス資料にある補足：
- 複数のプログラミング言語を学ぶ（C、C#、JavaScript、SQL、PHP、Processing、Pure Data、Python、Java、Swift など）。
- データベースは難易度の高い必修科目。
- 2年生で C 言語を全コース必修で学ぶ（プログラミング入門の資料より）。

## 3. 過去のガイダンスの変遷（2016〜2025年度）

いずれも小橋が担当（多くはコース長 田近先生の代理）。

### 2016年度
- Prezi のスライド＋60分の問題解決演習。
- 演習「円環シリトリ」：全員が同時並行でシリトリを作る共同作業。既出単語・ネット検索OK、各単語に画像を貼る、最後の単語が最初に戻る輪にする。作業場所は Office365 の OneNote for Class。学籍番号を間隔を空けて書き、上下の人とつながるよう単語を調整する。

### 2017年度（90分で講義と実習）
- システムとは：漢字の「明」は日＋月。日でも月でもなく、全体で明。ビャンビャン麺の漢字。
- システム＝構成要素すべてが一体となって機能する仕組み。例：時計（時間を計る仕組み）、ピタゴラ装置（ルーブ・ゴールドバーグ・マシン）。
- システムと情報：ハードウェア＋ソフトウェア。ハンディカムを分解すると部品を電気信号で制御している（プログラムが必要）。自動車、地図＋ナビ、Web＋検索サイト。
- データベースは情報システムの代表。例：メディア芸術データベース。「Google 検索との違いは？」
- 映画のプログラミングシーンと本物の違い。プログラマーのイラストの12行目にあるバグ探し。
- シラバス検索で「何か変だ」を見つける → システムの実装・運用・改善。「顧客が本当に必要だったもの」。
- AI の活用：伝統的プログラミングと機械学習の比較、AI 作曲、AI が描いたレンブラント、Inceptionism。
- 余談：ライブコーディング、卒業生の音楽演奏システム。人間もシステムの一部（操作ミスへの対処、使いやすいデザイン）。
- 28x＋30y＋31z＝365、x＋y＋z＝12 を数式処理システムで解く。

### 2022年度
- 田近コース長によるプレゼン（pptx、2022年9月29日に使用）。内容は未取得。

### 2023年度「シン・情報システム2023」（2023年9月28日）
- 導入：田近先生版と小橋版のどちらを聞くか、学生が手を振って選ぶ「プレゼン選択システム」。
  構成：360カメラ → iPad → ミラーリング → Windows PC（apowerMirror → OBS → NDI）→ Max8 のオプティカルフロー解析 → 結果表示UI。
- 卒業シミュレータで情報システムコースの単位履修計画を見せる。
- 時間が足りないので「情報システム的解決」として動画を並列再生。
- 自動人間洗浄システムの開発を例に、システム開発の流れ：要件分析 → 設計 → 実装 → 運用テスト → メンテナンス。「最後は手作業で仕上げる。完璧なシステムは必要か？」
- システムとは：色々組み合わさって機能する仕組み。単体では機能しないもの。ハード・ソフトに限らない（ウェットウェア）。身近な巨大システム、社会システムやルールなど概念的なシステムもある。
- 「デザイン？No → サウンド？No → 映像？No → システム」という選び方で大丈夫ですか？
- 締め：このページ自体を作るのに使ったサービス（Google Sites、X、DeepL、ChatGPT、Midjourney、Wikipedia、Google 検索の生成AI機能、YouTube、Prezi）も、幾つもの情報システムから成り立っている。

### 2024年度（2024年10月3日）
- Google スライド中心。キーワード：RPA、ENGINEER、GPT、AUTOMATION、PROGRAMMING、SYSTEM。
- 4コースの「作業が壊れてキレる場面」の比較と「あなたが耐えられるストレスは？」
  - 情報システム：プロジェクトが壊れてキレる
  - 映像メディア：レンダリングで固まってキレる
  - サウンド制作：ミックスダウンで落ちてキレる
  - メディアデザイン：印刷不良でキレる
- 動画：映画のプログラマーと現実のプログラマー、ルーブ・ゴールドバーグ系 ほか。

### 2025年度
- 情報メディア学科4コース適性診断アプリ（2025年9月30日、ChatGPT で生成。Node.js、React、Tailwind、Vite、TypeScript）。
  前置き：「尤もらしさと正しさの違いに注意」「占い程度に参考になるかも」。
- カリキュラムツリー、複数のプログラミング言語を学ぶこと、データベースは上級の必修。
- 「楽なコースは有りません」（2024年度スライドから引用）、「消去法は非推奨」。
- ネタ動画：映画と現実のプログラマー、エンジニアリング＝問題解決と試行錯誤（狭い橋を渡るには？）、システムとは（明＝日＋月）、究極のシステム（役に立たない機械／究極の機械：ムナーリ、ミンスキー、シャノン、モイゼス）、ルーブ・ゴールドバーグ・マシン、害獣対策の DX、LLM の仕組み。

## 4. 毎年続いている柱（2026年度も引き継ぐ）

1. **システムとは**：明＝日＋月、単体では機能しない、ルーブ・ゴールドバーグ、究極の機械。
2. **現実のエンジニアリング**：映画と現実のプログラマー、バグ探し、問題解決と試行錯誤、システム開発の流れ。
3. **その年の最新AI**：2017年の機械学習 → 2023年の ChatGPT・Midjourney → 2025年の LLM と生成アプリ → 2026年は Claude Code で作ったアプリそのもの。
4. **学生が体験する仕掛け**：2016のシリトリ、2023の挙手システム、2025の診断アプリ → 2026は VR プレゼンと学生用ゲーム。
5. **コースの選び方**：楽なコースは無い、消去法で選ばない。

## 6. 技術メモ

### mocopi（VRプレゼンアプリ用）
- mocopi Receiver Plugin for Unity（Sony 公式）を使うと、mocopi アプリが送信したモーションデータを Unity のアバターに適用できる。GitHub: sony/mocopi-receiver-plugin-unity（Apache License 2.0）。
- スマホ（mocopi アプリ）と PC（Unity）をローカルネットワークで UDP 接続する。
- mocopi アプリ側：モーション画面で「送信」に切り替え、送信先 PC の IP アドレスと UDP ポート（初期値 12351）を指定。送信フォーマットは「mocopi (UDP)」。
- アバターは FBX などのヒューマノイドモデルが使える。
- 繋がらないときは、まず PC のファイアウォールを疑う。
- 学内 Wi-Fi は端末間通信が遮断されている可能性があるため、持ち込みルーターかテザリングを使う。

### 公開（学生用ゲーム）
- GitHub Pages で公開する。学生はアカウント不要でスマホのブラウザから遊べる。
- claude.ai の共有リンクは、閲覧にClaudeアカウントが必要な場合があるため、学生への配布には使わない。
- main ブランチにマージした内容がそのまま公開される。ガイダンス当日までは URL を配らない。
